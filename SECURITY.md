# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in cloud-itonami-isco-3121, please
do NOT open a public issue. Instead, email the maintainers directly at
security@cloud-itonami.io (if such an address exists, or use the primary
project contact).

Provide:
- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 48 hours and work with you to resolve
the issue responsibly.

## Security Best Practices

- Keep dependencies up to date.
- Follow secure coding practices.
- Never commit sensitive data (secrets, API keys, etc.).
- Review audit logs regularly.

## Compliance

This project follows the Open Occupation Blueprint security principles:
all operations are logged to an immutable audit ledger, and no automated
action bypasses governor validation.
